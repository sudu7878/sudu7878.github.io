grapesOS

This project is almost like my dream come true. I always wanted to develop and ideate my own Operating System from scratch: which isn't based on any pre-existing projects such as the Linux kernel. grapesOS is made for ARM v64 chip, specifically for Raspberry Pi 4 due to its open source nature. I plan to make this project as a whole gaming ecosystem that has 3D-rendering libraries by-default, while keeping the efficiency and performance of ARM chips. Check it out on GitHub!

WireSend

WireSend

I tried to make my own File-Transfer-Protocol interface using Linux and Unix skockets. It's a complete terminal based application (CLI interface). I created my own packet structure and used TCP/IP to send those over the wire. It also has basic command parsing thing for the session handling and file prompts. Everything here (except for tinyFD--an API for file prompt) is made from scratch. Note that this project only works on Linux (it should run on macOS as well since it uses UNIX libs, but I don't know Apple's implementation) but I haven't tested it.). Anyways, it's fun working with networking (oh wow this sentence rhymes well). Check it out on GitHub!
